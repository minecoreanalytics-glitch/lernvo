# Spec — HRIS integration (employees & org chart in, certificates out)

**Date:** 2026-08-19 · **Status:** implemented v1 (Odoo, CSV, push API)

## Why
People are the HRIS's source of truth; knowledge is Lernvo's. Importing employees/departments
removes double entry, triggers onboarding on hire, deactivates on departure, and keeps the org
chart identical to HR's. Writing certificates back makes Lernvo part of the HR process
(evaluation, promotion) — the main switching cost.

## Model
- `User.externalSource/externalId`, `Department.externalSource/externalId` (unique per tenant+source).
- `HrConnector(type ODOO|CSV|API, config JSON with secrets encrypted AES-256-GCM (key derived from JWT_SECRET),
  apiKeyHash, enabled, pushCertificates, deactivateMissing, intervalMinutes, lastRunAt)`.
- `HrSyncRun(source, status, stats, error)` — audit trail per tenant.

## Normalized payload (every connector produces it)
```
departments[]: { externalId, name, parentExternalId?, managerName? }
employees[]:   { externalId, email, firstName, lastName, role?, departmentExternalId? | departmentName?, managerExternalId?, hiredAt?, active? }
```
Rules: match by externalId (per source) then adopt by name/email; never downgrade
PLATFORM_MANAGER / HR / SUPER_ADMIN from an HR feed; new users get a temp password + welcome
email; `deactivateMissing` only touches users owned by that source.

## Connectors
| Type | Direction | How |
|---|---|---|
| **ODOO** | pull (scheduler, every `intervalMinutes`, min 15) + push certificates | JSON-RPC `hr.department`, `hr.employee`; certificates → `hr.resume.line` (hr_skills) or chatter note |
| **API** | push from n8n / Salesforce flow / any HRIS | `POST /api/hr/push` + `X-HR-Key` (per-tenant key, hashed at rest, shown once) |
| **CSV** | manual upload | `POST /api/hr/import-csv` (multipart), headers in FR/EN, `,` or `;` |

Admin UI: **Intégrations RH** (PLATFORM_MANAGER): create/test/run/toggle/delete connectors, rotate
API key, CSV import, runs history.

## Ops notes
- Rotating `JWT_SECRET` makes stored connector secrets unreadable → re-save Odoo connectors.
- Scheduler runs in-process every 5 min (`HR_SYNC_SCHEDULER=off` to disable). Single instance assumed.
- multer + AsyncLocalStorage: use `reenterTenant` after any `upload.single()` (see `middleware/auth.ts`).
